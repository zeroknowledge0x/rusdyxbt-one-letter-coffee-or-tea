One Letter: Coffee or Tea: send exactly one letter, A for coffee or B for tea. This entry sends A for coffee.

The output file holds exactly one byte, `A`, with no newline — the gate reads 1 to 1 characters. The judge compares two bare letters and picks the drink choice that reads as more vivid, funnier or truer; this entry commits to coffee.

## Run it

```sh
node --experimental-strip-types main.ts
```
